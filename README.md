# 🍔 American Caffetteria · Termez (100% Halal)

Официальный репозиторий легендарного кафе американского стритфуда и чайной карты в Термезе (Сурхандарья).

Включает в себя:
1. **Интерактивный веб-сайт и PWA** с адаптивным дизайном и полным каталогом.
2. **Нативное Android-приложение (APK)** на базе Capacitor с иконкой и заставкой в фирменном стиле.
3. **Telegram-бота и Telegram Mini Web App** (`@americancaffeteri_bot`) с мгновенным приемом заказов и регистраций клиентов в рабочую группу.
4. **Админ-панель управления** (`admin.html`) для операторов и поваров.

---

## 🌟 Возможности и функционал

* **Полное меню 73 позиции** — сочные бургеры из 100% отборной халяльной говядины на открытом гриле, хрустящий лаваш и тандыр-лаваш, пицца, пиде, хот-доги, салаты, суши, чизкейки Сан-Себастьян и авторский чай в чайниках.
* **100% Halal** — строгий контроль стандартов чистоты и качества сырья.
* **Мгновенная регистрация клиентов** — через сайт, Android-приложение, Telegram Web App и прямого диалога в боте с автоматической отправкой карточки гостя в группу кухни/администраторов.
* **Оформление и расчет доставки** — выбор самовывоза или доставки по Термезу (до 03:00 ночи) с автоподсчетом стоимости и бесплатной доставкой от 100 000 сум.
* **Интерактивный фильтр и корзина** — быстрый выбор категорий, калькуляция порций, модальные окна и звуковые эффекты.

## 🗂 Структура проекта

```text
├── index.html               # Главная страница сайта и PWA
├── app.js                   # Основная логика корзины, заказов, геолокации и Telegram SDK
├── menu_data.js             # База данных 73 авторских блюд с ценами и составом
├── style.css                # Фирменные стили в стиле крафтового американского дайнера
├── manifest.json            # Манифест PWA мобильного приложения
├── sw.js                    # Service Worker для кэширования
├── admin.html / admin.js    # Панель администратора и оператора
├── American_Caffetteria.apk # Готовый установочный файл Android приложения
├── images/                  # HD фотографии всех блюд, галереи и фирменные логотипы
├── telegram_bot/            # Исходный код Telegram-бота и HTTP сервера
│   ├── bot.py               # Бот на aiogram 3 + aiohttp сервер API
│   ├── requirements.txt     # Python зависимости
│   └── cafe_bot.db          # База данных пользователей и заказов (SQLite)
└── android/                 # Полный проект Capacitor Android Studio
```

## 🚀 Запуск и установка

### 1. Запуск Telegram-бота и локального сервера:
```bash
cd telegram_bot
pip install -r requirements.txt
python bot.py
```
* **Админ-панель доступна по адресу:** `http://127.0.0.1:8080/admin.html`
* **Логин:** `admin` | **Пароль:** `admin123!`

### 2. Установка Android-приложения:
Готовый файл `American_Caffetteria.apk` находится в корне проекта. Скопируйте его на любой Android телефон и установите.

Для пересборки через Gradle:
```bash
cd android
./gradlew assembleDebug
```
