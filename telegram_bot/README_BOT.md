# 🍔 Инструкция по запуску Telegram-бота и Mini Web App (American Caffetteria)

## Что умеет этот бот (`telegram_bot/bot.py`)
1. **Пошаговая регистрация пользователей**:
   - Запрашивает **Имя** и **Фамилию**
   - Запрашивает **Номер телефона** через нативную кнопку Telegram `📱 Отправить мой номер телефона` (`request_contact=True`)
   - Запрашивает **Геолокацию (GPS)** через кнопку `📍 Отправить мою геолокацию` (`request_location=True`)
   - Автоматически считывает **Telegram `@username`** и `user_id`
2. **Сохранение базы клиентов**:
   - Все пользователи автоматически сохраняются в базу `telegram_bot/users.db` (SQLite) и экспортируются в `telegram_bot/users_db.json`.
3. **Пересылка в рабочую Telegram-группу кафе**:
   - Каждая новая регистрация и каждый заказ из Мини-Веб приложения мгновенно отправляются в вашу рабочую группу (`GROUP_CHAT_ID`) вместе с кликабельным номером телефона, `@username` и точкой геолокации на карте!
4. **Telegram Mini Web App (Мини-Веб)**:
   - В главном меню бота есть кнопка **«🍔 Открыть Мини-Веб Меню (Mini App)»**, которая открывает сайт прямо внутри Telegram. Сайт автоматически распознает, что открыт в Telegram или с телефона, и включает мобильный режим приложения без ручного переключения.

## Как запустить за 3 шага

1. Установите библиотеку `aiogram`:
   ```bash
   pip install -r telegram_bot/requirements.txt
   ```
2. Откройте `telegram_bot/bot.py` и укажите:
   - `BOT_TOKEN` — токен вашего бота от `@BotFather`
   - `GROUP_CHAT_ID` — ID вашей рабочей Telegram-группы (добавьте бота в группу и сделайте администратором; узнать ID группы можно через `@userinfobot` или `@getmyid_bot`, обычно начинается с `-100...`)
   - `WEBAPP_URL` — HTTPS-ссылка на ваш опубликованный сайт (например, на Vercel, Netlify или GitHub Pages)
3. Запустите бота:
   ```bash
   python3 telegram_bot/bot.py
   ```
